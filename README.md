📊 US CO2 Emissions Dashboard on Databricks

📝 Project Overview

This project provides a comprehensive analysis and interactive visualization of carbon dioxide emissions across the United States. Built on the Databricks Lakehouse Platform, it processes large-scale environmental datasets to provide actionable insights into emission trends, industrial contributors, and geographic hotspots.

🌎 Authenticity & Data Integrity

Unlike projects using synthetic or outdated data, this dashboard is powered by real-world, official 2023 data from the U.S. Environmental Protection Agency (EPA). Specifically, it leverages the latest release of the Greenhouse Gas Reporting Program (GHGRP), reflecting the most current environmental status of large stationary sources in the US.

🚀 Key Features

    Real-Time 2023 Data: Direct ingestion of the EPA’s 2023 greenhouse gas data, covering approximately 8,000+ industrial facilities.

    Interactive Geospatial Mapping: Visualize emission intensity across different states and counties.

    Sectoral Analysis: Drill down into emissions by industry (Power Plants, Oil & Gas, Minerals, Waste, etc.).

    Trend Visualization: Comparative analysis of 2023 data against historical benchmarks to track the US's progress toward net-zero goals.

    Spark-Powered ETL: Efficient data cleaning and transformation using PySpark.

🛠️ Tech Stack

    Platform: Databricks (Azure/AWS/GCP)

    Language: PySpark (Python), Spark SQL

    Data Source: EPA 2023 Greenhouse Gas Reporting Program

    Visualization: Databricks SQL Dashboards / Plotly / Matplotlib
